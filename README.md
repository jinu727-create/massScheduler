# massScheduler — 독서단 미사 배정

성당 독서단의 월별 미사 일정을 자동으로 만들고, 해설자·독서자를 공정하게 자동 배정해 캘린더로 보여 주는 웹앱입니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `logic.js` | 미사 자동생성, 봉사자 자동배정 알고리즘 (순수 함수, Node에서도 실행 가능) |
| `index.src.html` | 화면(UI) 소스. `/*LOGIC*/` 자리에 `logic.js`가 들어갑니다 |
| `index.html` | `logic.js`를 합친 최종 단일 파일 (claude.ai 아티팩트로 게시) |
| `seed.js` | 예시 멤버 26명으로 배정 규칙을 검증하는 테스트 |
| `build.sh` | `index.html` 다시 만들기 |

## 빌드 · 테스트

```bash
./build.sh        # index.src.html + logic.js → index.html
node seed.js      # 배정 결과와 규칙 위반 건수 출력
```

## 배정 규칙 요약

- 평일 미사: 해설 1, 독서 1 / 주말 미사: 해설 1, 독서 2
- 역할·배정 가능 시간대·불참일이 맞는 사람만, 하루 1회
- 부부독서는 같은 미사에 함께 (주말: 독서 2명 또는 해설+독서, 평일: 해설+독서)
- 날짜순으로 배정하며 이번 달 횟수, 주말 같은 시간대 반복, 같은 주 중복, 지난달 횟수를 점수로 반영
- 50번 시도해 빈 자리 → 횟수 편차 → 시간대 반복 순으로 가장 좋은 결과 채택

## 데이터 (Claude 내장 DB)

- `app/members` — `{ list: [멤버...] }`
- `app/config` — `{ templates, weights }`
- `months/YYYY-MM` — `{ masses: [미사...] }`

쓰기 권한은 아티팩트 소유자와 편집자(admin)만 가집니다.
